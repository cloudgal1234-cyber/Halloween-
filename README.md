# 🎃 מפת האלווין של רעות

מפה אונליין לסיבוב ממתקים: מיקום חי, רשימת בתים לפי מרחק, התראה כשמגיעים לבית, סימון ✓ וניווט לכל בית (מסלול הליכה במפה + Google Maps / Waze).

- `index.html` – האפליקציה (קובץ אחד, Leaflet + OpenStreetMap)
- `original-map.jpg` – המפה המקורית

בפתיחה הראשונה הדף מאתר את כתובות הבתים דרך OpenStreetMap (כדקה) ושומר במכשיר. בית שמופיע במקום לא נכון – תפריט ☰ ← "מצב תיקון" וגוררים אותו. אפשר לייצא את המיקומים המתוקנים ולייבא במכשיר אחר.

הפעלה: GitHub Pages (Settings → Pages → Branch) או כל אחסון סטטי עם HTTPS (נדרש בשביל המיקום).
